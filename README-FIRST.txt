# NIRIKSHAN — Simple IntelliJ Package

This package keeps frontend and backend separate.

1. Extract this ZIP.
2. Open NIRIKSHAN-backend in IntelliJ.
3. Run NirikshanApplication.java.
4. Open NIRIKSHAN-frontend/index.html in a browser (or IntelliJ's local preview).
5. Use CSV Import -> Validation -> Risk Engine -> Dashboard.

Backend: http://localhost:8080
The included CSV is synthetic demo data.
